# 多平台主页简介生成指南

## 核心目标

简介是陌生人进入主页后判断“是否值得信任、是否值得继续看、是否需要咨询”的入口，不是内部定位文档的缩写，也不是企业广告口号。

先形成一套统一定位基线，再适配抖音、小红书和视频号。平台表达可以变化，真实身份、业务、目标客户、案例和核心价值不能变化。

## 统一定位基线

从已确认信息中选择最强的 2—3 个锚点：

1. 身份锚点：企业角色、真实职业、行业、区域或从业经历。
2. 业务锚点：主营产品或服务、服务对象和典型购买场景。
3. 证明锚点：真实案例、作品、项目、方法、年限或客户反馈。
4. 价值锚点：能够帮助目标客户看懂、判断、避坑或解决的问题。
5. 行动锚点：正在进行的项目、连续记录、现场实践或服务过程。
6. 人格锚点：自然、有辨识度且用户愿意长期使用的表达和经营理念。

优先使用有事实依据的身份、案例、方法和行动。用户没有强履历时，用真实业务过程和持续行动建立可信度，不要创造专家头衔。

## 简介结构

从以下信息中选择最有价值的 3—4 项，每行只承担一个主要作用：

- 我是谁，以及为什么值得听；
- 我经营什么，服务哪类目标客户；
- 我持续讲什么问题，提供什么价值；
- 有什么真实案例、方法或行动可以证明；
- 用户可以通过什么合规方式进一步了解或咨询。

不要把这些问题直接写成“我是谁、我能帮谁”的填表标签。简介应像老板本人自然介绍自己。

## 三种包装角度

### 专业信任型

使用“真实身份或业务 + 专业判断 + 客户价值”。适合已有行业积累、案例或稳定业务的老板。

### 案例证明型

使用“真实案例或项目 + 解决的问题 + 持续分享方向”。适合家居建材、装修和其他项目型服务企业。

### 老板人格型

使用“经营理念或人物特点 + 行业视角 + 内容承诺”。适合希望形成长期品牌、增强熟人信任和团队形象的老板。

方案必须体现信息结构差异，不能只更换昵称或同义词。

## 平台适配

### 抖音

- 口语直接，前置身份、业务或真实证明；
- 快速说明“为什么值得看”和持续内容方向；
- 强调现场、案例、观点和行动感；
- 咨询入口必须符合平台规则，避免硬广和夸张承诺。

### 小红书

- 突出具体问题、经验价值和可收藏信息；
- 适合强调选购、避坑、案例细节、审美和决策方法；
- 避免广告腔、空泛头衔和密集联系方式；
- 家居建材和装修内容要清楚区分经验分享与商业宣传。

### 视频号

- 强化真实身份、企业角色、行业积累、地域或企业背书；
- 兼顾熟人信任、客户转介绍和长期品牌；
- 表达可以更完整稳重，突出经营理念、案例和服务承诺；
- 不把未经确认的企业规模、客户数量或行业地位写入简介。

## 避免机械和空泛表达

除非用户明确喜欢，否则避免：

- 使用“赋能、顶级、全网第一、行业领军”等缺少证据的抽象头衔；
- 罗列过多行业、产品和人群，让人看不出重点；
- 只写“关注我、一起成长、欢迎咨询”等没有具体理由的行动号召；
- 把账号写成企业宣传栏，没有老板本人和真实观点；
- 为了活泼堆叠大量表情符号；
- 添加用户未确认的公司、职位、年限、案例、客户评价、数据或成果；
- 三个平台复制同一段简介，不做任何表达适配。

## 结构示例

示例只用于理解结构，不得复制其中的身份、业务和案例给用户。

```text
某家居门店主理人｜长期在一线服务客户
讲清选材、预算和交付中最容易踩的坑
只分享亲自做过、现场能验证的案例
```

```text
装修公司经营者，记录真实项目和返工教训
从客户决策到现场交付，把复杂问题讲明白
希望你装修前多一个可靠判断
```

```text
一个认真做实体生意的老板
分享经营选择、客户问题和团队现场
先把信任做实，再谈生意
```

## 验收标准

1. 三秒内能否看懂这个人是谁、经营什么？
2. 能否知道主要服务哪类客户、持续讲什么？
3. 是否有一个真实、具体、能被记住的可信细节？
4. 是否同时支持专业信任和自然获客？
5. 抖音、小红书、视频号是否各有表达侧重？
6. 三个平台的身份、业务和核心价值是否一致？
7. 所有身份、案例、结果和数字是否经过用户确认？
8. 是否自然得像本人介绍，而不是 AI 总结定位表？
