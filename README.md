# 个人IP背景访谈

> 胡涂涂账号定位访谈专用 Skill。

`personal-brand` 面向企业老板、创始人和门店经营者，通过一对一渐进访谈，帮助你完成个人背景定位、账号定位、内容定位，以及抖音、小红书、视频号多平台账号包装。

Skill 优先适配家居建材、家居服务和装修公司，同时兼容其他实体行业。它不会预设你的赛道，而是根据真实业务、目标客户、案例和个人优势生成定位，兼顾品牌信任与获客成交。

## 它能帮你完成什么

1. 梳理老板的真实身份、企业角色、经历、经营理念和可信依据。
2. 明确所属行业、主营业务、目标客户、客户痛点和差异化优势。
3. 形成兼顾专业信任、品牌影响力与客户咨询的账号定位。
4. 生成 2—4 个动态内容支柱和前 5 条精准起步选题。
5. 生成抖音、小红书、视频号的差异化昵称、简介、头像和背景图建议。
6. 在你确认最终结果后，自动创建或更新 Obsidian 定位文件。

## 使用前准备

先在 Obsidian 中创建并打开一个内容创作 Vault，至少包含：

```text
个人IP内容创作系统/
└── 00_个人背景/
```

你可以根据需要继续添加案例库、选题库、内容草稿和发布复盘等文件夹。再用 Codex 打开这个 Vault，确保 Codex 可以读取和修改其中的 Markdown 文件。

## 安装方法

把下面这段话发送给 Codex：

```text
请使用 skill-installer 安装这个 GitHub Skill：
https://github.com/meloto2022/Personal-IP
```

安装完成后，可以直接说：

```text
请使用 personal-brand 开始个人IP背景访谈。
```

Skill 会说明接下来的四个阶段，并给出个人背景定位的第一个问题。

## 使用方法

按照 Skill 的问题逐个回答即可：

```text
个人背景访谈
→ 确认个人背景定位
→ 企业与账号定位访谈
→ 确认账号定位
→ 内容定位访谈
→ 确认内容定位
→ 生成并确认多平台账号包装
→ 自动写入 Obsidian
```

回答时请遵守三个原则：

- 尽量提供真实经历、客户问题、案例、动作、结果和踩坑过程。
- 想不起来时直接说“暂时想不起来”，不要为了完成定位而编答案。
- AI 总结后认真检查；不准确的地方直接说明真实情况。

## 内容方向

本 Skill 不预设固定赛道，而是根据老板的行业、业务、目标客户、真实案例和个人优势生成内容定位。重点适配家居建材、家居服务和装修公司，也支持其他实体行业。

内容方向可包括：

- 行业认知与老板观点；
- 客户痛点、选购决策与避坑知识；
- 真实案例、项目复盘与结果展示；
- 产品、服务、工艺与交付过程；
- 企业经营、团队故事与创业经历；
- 客户常见问题及解决方案。

前 5 条内容优先用于建立专业信任、筛选精准客户，并为后续咨询与成交建立自然承接。

## 多平台账号包装

Skill 先生成一套统一定位基线，再分别适配：

- 抖音：突出身份、现场、案例、观点和行动感；
- 小红书：突出具体问题、经验价值、选购决策和可收藏信息；
- 视频号：突出企业角色、行业积累、经营理念和长期信任。

平台表达可以不同，但不会改变已经确认的身份、企业、业务、客户和案例事实。

## 最终生成文件

多平台包装确认后，Skill 会自动创建或更新：

```text
00_个人背景/定位总览_v0.1.md
00_个人背景/账号包装_v0.1.md
```

定位总览会保存企业、业务、目标客户、可信依据、内容支柱和品牌获客逻辑；账号包装会保存统一定位基线及三个平台的适配方案。

Skill 只会写入你已经确认的信息。无法确认的内容会标记为“待确认”，不会替你补全身份、案例、客户评价、经营数据或成果。

## Skill 文件结构

```text
personal-brand/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
│   ├── interview-guide.md
│   ├── profile-bio-guide.md
│   └── output-templates.md
└── tests/
    └── validate-positioning-scope.sh
```

- `SKILL.md`：访谈流程、阶段规则和自动写入逻辑。
- `interview-guide.md`：分阶段问题、追问方法和信息充足标准。
- `profile-bio-guide.md`：统一定位基线、多平台简介结构和验收标准。
- `output-templates.md`：Obsidian 定位文件的固定结构。
- `validate-positioning-scope.sh`：检查固定赛道残留和跨文件一致性。
